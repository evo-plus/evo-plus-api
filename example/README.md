# Example Addon

Минимальный Fabric-мод на Java, который встраивается в EvoPlus через evo-plus-api.
Отдельный Gradle-проект: в сборку API он не входит.

## Что показывает

| Файл | Что внутри |
|---|---|
| `ExampleMod` | сам мод, без единого упоминания EvoPlus: считает удары по блокам |
| `ExampleConfig` | собственный конфиг мода — для примера `bind` |
| `integration/ExampleEvoPlusAddon` | точка входа `evo-plus`: категория и секция, переключатель, строка, клавиша с уведомлением, цвет, выбор из enum с подписями, число из своего конфига через `bind`, кнопка, `onSave`, `visible` |
| `integration/ClockWidget` | виджет HUD: фон, рамка, текст, предмет, поворот, обрезка, ванильный вызов, размер под содержимое, заглушка в редакторе |
| `fabric.mod.json` | две точки входа (`client` и `evo-plus`), EvoPlus в `suggests`, а не в `depends` |

Всё, что касается EvoPlus, лежит в пакете `integration` и трогается только из точки входа
`evo-plus`. Без EvoPlus её никто не вызовет, классы API не загрузятся — мод работает сам.

## Как запустить

1. Скопировать папку `example` отдельным проектом и подставить свой `mod_id`, пакет и
   имена в `fabric.mod.json` и lang-файлах.
2. Положить jar EvoPlus в `run/mods` (или подключить как `modLocalRuntime`), чтобы в
   dev-клиенте была реализация API.
3. `./gradlew runClient`, зайти на сервер, открыть меню EvoPlus → «Аддоны» → «Настройки»
   у Example Addon, включить виджет и поставить его в редакторе виджетов.

Подробности по API — в [README репозитория](../README.md).
